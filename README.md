# 🎬 AppFilme

Um aplicativo iOS desenvolvido em Swift para quem quer descobrir novas histórias sem complicação. O **AppFilme** centraliza um catálogo de produções e entrega o que você realmente precisa saber antes de dar o *play*.

---

## 🎯 O Intuito do App

O principal objetivo do **AppFilme** é servir como um **guia rápido e direto de sinopses e categorias**. Ele foi feito para o usuário que quer abrir o aplicativo, navegar pelos títulos disponíveis e entender na hora sobre o que é o filme e qual o seu estilo.

Ao clicar em um filme do catálogo, o app apresenta três informações cruciais:
*   **Título:** O nome do filme em destaque.
*   **Gênero:** A classificação do filme (Ação, Romance, Comédia, Drama, Ficção Científica, etc.), ajudando o usuário a escolher o que melhor se encaixa no seu humor no momento.
*   **Descrição:** A sinopse detalhada da história, permitindo que você conheça o enredo de forma clara e objetiva.

## 🛠️ Tecnologias Utilizadas

*   **Linguagem:** Swift
*   **Interface:** Desenvolvido nativamente para dispositivos Apple (iOS)
*   **Ambiente de Desenvolvimento:** Xcode

---

## 🚀 Como Executar o Projeto

1. Baixe ou clone este repositório para o seu Mac.
2. Abra a pasta do projeto e abra o arquivo principal do Xcode (com extensão `.xcodeproj`).
3. Escolha o seu simulador de iPhone de preferência.
4. Pressione `Command + R` no teclado para rodar e testar o aplicativo.
